# Retail Sales Analytics Dashboard

## Overview

This project analyzes retail sales data to identify business trends, customer purchasing patterns, and profitability insights. It includes data cleaning, exploratory data analysis (EDA), machine learning for profit prediction, and an interactive Tableau dashboard for business reporting.

---

## Objectives

- Clean and preprocess retail sales data.
- Analyze sales, profit, and customer trends.
- Predict profit using a machine learning model.
- Create an interactive Tableau dashboard.
- Generate actionable business insights.

---

## Dataset

**Dataset:** Sample Superstore Dataset

**Features include:**
- Order Date
- Ship Date
- Customer Information
- Product Details
- Category
- Region
- Sales
- Quantity
- Discount
- Profit

- R² Score
